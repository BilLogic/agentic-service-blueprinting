**The prose checks and the commit sweeps name their subject.** Every check
that read documents — the doc-path resolver, the pointer check, the docs
index, the dependency-kinds rulebook sweep, the router budget, the negation
ratchet, the glossary shape — receives its files from the sweep's `docs`
subject; the two that read everything a commit would carry (the standalone
and content-coupling sweeps) and the reference-path check name a `commit`
subject the sweep now answers from `git ls-files`, the eighth beside the
seven the plan named; the identifier manifest reads the reference surface,
`references/` and each skill's own, from the `references` subject. None of
them resolves a root from its own location, walks a directory or handles a
vanished file any more, and their tests hand files in. The swept-docs list
and the commit-subject helper are gone; their guard tests are the sweep's.
