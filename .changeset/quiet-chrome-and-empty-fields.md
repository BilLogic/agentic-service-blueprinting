Every shared control now applies the same colour JOB as the design system these primitives were ported from, spelled in this system's semantic names. No mix dial moved — the numbers already matched, and what was wrong was which job got applied. The defect that started it: a placeholder sat on caption grey, the colour of text somebody had typed, so an empty field read as one that already held a note.

**Empty, locked, sunk, raised.** Empty Input, Textarea, select and command search take hint grey (`tertiary-foreground`). Input, Textarea and the input group sit on `bg-field`, the well this system already derived for text entry, instead of borrowing the page colour through `bg-transparent` and a dark-mode `input/30` wash. The select trigger sits on `bg-control-raised` with the control-hover edge, so a chooser is raised where a field is sunk. A read-only Input reads as a caption on the ordinary border rather than as an open well; disabled still fades the whole control.

**Floating chrome and badges.** A tooltip is a page-coloured surface with ordinary ink, plus the overlay ring every other floating surface carries, in place of an inverted ink slab. A dialog sits on the page surface, not the card plate. A sheet overlay is the page colour at high opacity, so the page stays faintly visible rather than greyed out. The default badge is a quiet tag — page-adjacent fill, caption ink, control edge — because a badge describes the thing it sits on and a primary fill read as an action. An outline button keeps the page colour in dark as well as light; a ghost button lifts on hover with `accent` rather than `muted`, the elevation a resting plate sits at; a destructive button is a solid fill with its own ink, because a 10% tint read as a badge describing a risk rather than a button that performs one.

**Quiet chrome.** Descriptions, inactive tabs, the select chevron and section label, command group headings and shortcuts, dropdown labels and submenu chevrons, menu shortcuts, and breadcrumb links and separators all drop one rung to hint grey. An inactive tab is one job now instead of an opacity in light and a different token in dark. Captions that must stay readable do not move: the sheet description, the alert description, the breadcrumb trail and the input-group addon — nor does a breadcrumb's current page. An unchosen select option and a resting toggle take caption grey. The select popup's raw `foreground/10` ring and the command separator's page divider both become the overlay edge, and a selected command row takes the accent lift.

**Vocabulary.** `compat.css` and its three alias names (`foreground-light`, `foreground-lighter`, `foreground-muted`) are gone, with a ratchet that refuses their return — a second spelling with no consumers reads as available, so adopting a borrowed snippet means rewriting it into `muted-foreground` or `tertiary-foreground`, not re-registering the alias. Two ramp-rule exemptions retire with the raw black and white they covered.

Unchanged, deliberately: the focus-ring formula, primary as the filled control, and the derived alert role surfaces — the mechanisms ADR 0008 records as this system's own. Each vendored file says in a header which job changed and why, per ADR 0014, so a re-vendor is a merge rather than a surprise.
