**Each input a deployment owned inside the application tree has a config
home, named in one place.** The org name is `brand.name`, the agent's role
overlay is `agent.doctrine`, its reference documents are `agent.references`,
and the pre-database board is `sample.nav`; the template's file at each old
path is the default, reached only when the field is absent. The customization
reference lists the fields — those four, the cover and the accent beside them
— what each replaced and how each is read, and
the owned-content inventory test carries all four through the config with no
file in `src` — the shape a deployment with no residents supplies. The
generated database types are the one file a deployment keeps on purpose,
held to the template's by the superset check.
