A vendored file names the decision it diverges for, never the record number.

Sixteen headers added with the colour-job pass cited `ADR 0014`, and one cited `ADR 0008`. A record number belongs to the repository that assigned it: a deployment reading `ADR 0014` in a file it shares with this template resolves it against its own records, where 0014 is a different decision or none at all — so the reader lands on the wrong page and believes they have the reason. The headers now say it in words, and a test holds the rule where the files are written rather than leaving it to a deployment's gate to catch after release.
